Wildcard hosts in `hosts` entries: `*.harianto.dev` is now a valid host and routes `foo.harianto.dev` to `{path}/subdomains/foo/public/`. Previously any `*` failed host validation (400), so `*.domain.tld` could only be approximated by the `autoSubdomains` flag on an exact entry. Matching order is now: exact host → `*.apex` entry → `autoSubdomains` fallback.
